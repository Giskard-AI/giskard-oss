# giskard-scan

Agent vulnerability scanner — red teaming, prompt injection, and adversarial scenario generation.

```bash
pip install giskard-scan
```

Requires Python 3.12+.

**Documentation:** install, quickstart, and usage live in the [root README](../../README.md#giskard-scan--vulnerability-scanner-for-ai-agents).

**Telemetry:** depends on `giskard-core`. See [Telemetry](../giskard-core/README.md#telemetry).

## Development

From the repository root — see [CONTRIBUTING.md](../../CONTRIBUTING.md):

```bash
make test-unit PACKAGE=giskard-scan
```
