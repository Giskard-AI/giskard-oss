# giskard-checks

Testing and evaluation for agentic systems — scenarios, built-in checks, and LLM-as-judge.

```bash
pip install giskard-checks
```

Requires Python 3.12+.

**Documentation:** install, quickstart, and API usage live in the [root README](../../README.md#giskard-checks--create-and-apply-evals-for-testing-agents) and on [docs.giskard.ai](https://docs.giskard.ai/oss/checks).

**Telemetry:** depends on `giskard-core`. See [Telemetry](../giskard-core/README.md#telemetry).

## Development

From the repository root — see [CONTRIBUTING.md](../../CONTRIBUTING.md):

```bash
make test-unit PACKAGE=giskard-checks
```
